    Tip
    • 시안 ID 입력 후 Enter 1회: Preview 불러오기
    • 불러오기 완료 후 Enter 1회 더: 이미지 저장하기
    • 리스트는 최대 20건 누적 가능, 시안 ID를 콤마로 다건 입력하면 일괄 불러오기 가능
    • 원본 Preview 팝업 보기는 원본 페이지를 육안 확인하는 보조 기능입니다.

    Tip
    • 데이터 반영하기: 입력한 정보를 우측 캡처 미리보기에 반영
    • 이미지 저장하기: 반영 이후 변동이 없을 때 활성화되어 PNG로 저장
    • 데이터 불러오기 / 데이터 저장하기: 입력값을 JSON 파일로 저장하거나 불러오기
    • 로고 파일 등록 시 브라우저 내부에 저장
    • 에디터 단축키: Ctrl(Cmd) + B : 진하게, Ctrl(Cmd) + U : 밑줄, Ctrl(Cmd) + Shift + L : 리스트
